# RightJob – AI-Powered Resume Analysis Platform

An intelligent web application that provides AI-driven resume feedback and personalized job recommendations using Natural Language Processing (NLP). Integrated with the **Cohere AI API** to deliver real-time, actionable suggestions for resume improvement and career alignment.

---

## Project Overview

RightJob helps job seekers and career counselors by analyzing resumes and recommending suitable job roles:

- **AI-Powered Resume Analysis:** Provides improvement suggestions based on NLP analysis.  
- **Personalized Job Recommendations:** Suggests job roles with live opportunity links.  
- **PDF Report Generation:** Generates reports for career guidance.  
- **User-Friendly Interface:** Designed for both job seekers and career counselors.  

This project was developed as part of the **Entrepreneurship in Computing** course. This is developed in a team that consist of three members.
